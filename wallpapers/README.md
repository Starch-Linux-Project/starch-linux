# Starch wallpapers

During the ISO build, supported images in this directory are staged into
`/usr/share/backgrounds/starch` for both the live and installed COSMIC desktop.
COSMIC Settings discovers these images in its wallpaper chooser.

`default.txt` selects the wallpaper for new accounts. It contains one image
path relative to this directory. If the selector or image is missing, COSMIC
uses its usual default and the other supplied wallpapers remain available.

Supported extensions are AVIF, JPEG, JPG, JXL, PNG, and WebP.
