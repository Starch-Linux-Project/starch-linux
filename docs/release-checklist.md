# Release checklist

- [ ] Reviewed provenance and redistribution basis for all live packages
- [ ] Immutable source revision and clean reference build
- [ ] Exact live and target package manifests and component versions
- [ ] ISO SHA-256 and required corresponding source/notices
- [ ] BIOS and UEFI boot/install pass
- [ ] Multi-disk destructive-install safety pass
- [ ] Network, signature and package failure tests pass
- [ ] Core-service manifest approved by the project
- [ ] Physical daily-driver matrix and pilot complete
- [ ] Known limitations and online erase-disk warnings published

All release gates remain open. The current source is not a release candidate.
