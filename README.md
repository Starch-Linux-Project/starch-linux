# Starch Linux Beta

This repository is for beta development and testing of Starch Linux, an
Arch-based Linux distribution made by SethDoesTech. 

This is an experimental beta, not a stable release. Features may change and
things may break. Test in a virtual machine before using real hardware.

**Installation erases the selected disk. Back up your data before installing.**

See [docs/](docs/) for technical documentation and [LICENSE](LICENSE) for the
license.
