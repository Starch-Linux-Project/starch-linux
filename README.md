# Starch Linux

Starch Linux is an Arch-based Linux distribution built to make the benefits of Linux more accessible. It combines Arch's rolling package base with a configured desktop, a graphical installer, and its own desktop defaults and branding.

This is written for the 1.3 release

## System components

| Component | Standard installation |
| --- | --- |
| Package base | Arch Linux, managed by pacman |
| Kernel | Linux LTS (`linux-lts`) |
| Init and service management | systemd |
| Desktop | KDE Plasma on Wayland |
| Login manager | SDDM |
| Bootloader | Limine, with UEFI and legacy BIOS support |
| Root filesystem | ext4 |
| Networking | NetworkManager |
| Audio | PipeWire, PipeWire's PulseAudio server, and WirePlumber |
| Firewall | nftables |
| Compressed swap | zram with Zstandard compression, sized to half of RAM up to 4 GiB |

The desktop includes Firefox, Nautilus, COSMIC Terminal, COSMIC Text Editor, VLC, and a selection of KDE and GNOME utilities. Flatpak is included alongside pacman. Linux Update Utility is bundled as an AppImage with desktop integration.

## Boot and installation architecture

The live ISO is built with Archiso and uses the regular Arch Linux kernel, systemd, and Plasma Wayland. Its boot paths use Syslinux for BIOS and systemd-boot for UEFI. The live filesystem is compressed with SquashFS and XZ.

Installation uses Calamares with Starch-specific modules for dependency checks, package installation, system configuration, Limine setup, and final validation. The installer creates a fresh system from repository packages through pacstrap. The live environment's package set and user accounts are separate from the installed system.

The current partitioning configuration provides whole-disk installation with an ext4 root filesystem. Manual partitioning, automated disk encryption, and LVM are disabled. Swap is provided through zram instead of a disk partition.

Installed UEFI systems boot a unified kernel image generated by mkinitcpio, containing the kernel, initramfs, and kernel command line. BIOS installations use separate kernel and initramfs files. Both installed boot paths use Limine.

## Installation profiles

The Installation Profiles page offers KDE Plasma LTS (recommended default), COSMIC LTS, and Starch Lite (Xfce, Linux Zen, OpenRC). Exactly one can be selected. See [profile behavior and validation](docs/installation-profiles.md).

## Starch Lite

Starch Lite is an optional installation configuration with the same Starch identity and branding. It replaces Linux LTS and systemd with Linux Zen and Artix's OpenRC stack, including elogind for session management.

Lite draws its base and service packages from Artix's `system`, `world`, and `galaxy` repositories, with Arch `extra` supplying additional packages. Arch `core` is disabled for Lite. The standard installation and live ISO retain their Arch repositories and systemd runtime.

Lite uses Xfce on X11 and replaces the Plasma desktop and many of its associated applications. The Starch Lite package supplies session integration, an audio supervisor for PipeWire and WirePlumber, an OpenRC zram service, and desktop defaults. Lite retains Limine and the ext4 installation layout.

## Source layout

| Directory | Contents |
| --- | --- |
| `archiso/profile/` | Live image package list, boot configuration, and filesystem overlay |
| `calamares/` | Installer configuration, branding, and local modules |
| `manifests/` | Baseline installed-system package list |
| `scripts/installer/` | Installation and target-system configuration logic |
| `scripts/build/` | Image staging and package build tooling |
| `packages/` | Calamares and Starch Lite package sources |
| `tests/` | Automated checks for build and installer behavior |
| `wallpapers/` | Desktop artwork |

Build artifacts include package inventories, source archives, build reports, and ISO checksums. These record the inputs and package versions used for an image; the upstream package repositories continue to roll.
